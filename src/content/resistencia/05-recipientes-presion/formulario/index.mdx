# Formulario Resumido: Recipientes Delgados a Presión

**Nomenclatura básica:**
* $p$ = Presión interna manométrica
* $r$ = Radio interior
* $t$ = Espesor de la pared

| Geometría | Tipo de Esfuerzo | Fórmula |
| :--- | :--- | :--- |
| **Esférico** | Esfuerzo normal ($\sigma$) | $\LARGE\sigma = \frac{pr}{2t}$ |
| **Esférico** | Esfuerzo cortante máximo ($\tau_{max}$) | $\LARGE\tau_{max} = \frac{\sigma}{2} = \frac{pr}{4t}$ |
| **Cilíndrico** | Esfuerzo circunferencial o tangencial ($\sigma_r$) | $\LARGE\sigma_r = \frac{pr}{t}$ |
| **Cilíndrico** | Esfuerzo longitudinal ($\sigma_l$) | $\LARGE\sigma_l = \frac{pr}{2t}$ |
